## 适用平台

越南语 Telex 目前支持 macOS 与 Windows。Linux 暂未接入越南语 Telex 按键流程。

## 开启越南语学习语言

1. 打开「偏好设置」（Windows 为「设置」）。
2. 进入「通用」。
3. 将「学习语言」改为「越南语」。

改为越南语后，候选词右侧会显示越南语译词。青简也会自动把离开中文后的输入目标切到「越南语 Telex」。

若以后将「学习语言」改回「英语」，这个目标会自动切回「英语」。

## 切换到越南语 Telex

### Windows

Windows 使用「中英切换键」进入越南语 Telex，不使用 Caps Lock。

1. 在「设置 → 通用」确认「中英切换键切换到」为「越南语 Telex」。
2. 使用已勾选的中英切换键切换：
   - 单击 `Shift`（默认）；
   - 或单击 `Ctrl`；
   - 或按 `Ctrl + Alt + Space`。
3. 切入后输入越南语 Telex；再次按同一切换键回到中文。

Windows 上 `Caps Lock` 仍只控制大小写，不用于切换到越南语。

### macOS

macOS 使用 `Caps Lock` 切换。

1. 在「偏好设置 → 通用」确认「Caps Lock 切换到」为「越南语 Telex」。
2. `Caps Lock` 亮起时输入越南语 Telex。
3. `Caps Lock` 熄灭后回到中文输入。

## 基本输入规则

越南语 Telex 使用常见的 Telex 键位：

| 输入 | 输出 |
|---|---|
| `aa` | `â` |
| `aw` | `ă` |
| `ee` | `ê` |
| `oo` | `ô` |
| `ow` | `ơ` |
| `uw` | `ư` |
| `dd` | `đ` |
| `s` | 锐声，例如 `as` → `á` |
| `f` | 玄声，例如 `af` → `à` |
| `r` | 问声，例如 `ar` → `ả` |
| `x` | 跌声，例如 `ax` → `ã` |
| `j` | 重声，例如 `aj` → `ạ` |

声调键只会在当前词已经有元音后生效。因此 `trai`、`rau`、`sau` 这类词中的 `r` / `s` 会作为普通字母保留。

## 选词与上屏

| 操作 | 按键 |
|---|---|
| 输入词间空格，继续组合短语 | `Space` |
| 提交高亮候选并关闭候选窗口 | `Enter` / `Tab` |
| 选择当前页第 N 个候选 | `1` 至 `9` |
| 翻页 | 当前设置里的翻页键 |
| 删除输入 | `Backspace` |
| 取消输入 | `Esc` |

`Space` 不是提交键。它会留在越南语输入缓冲中，用于输入 `em trai`、`là gì` 这类多词短语。`Enter` 才提交当前高亮候选并关闭候选窗口。

例如：

1. 切换到越南语 Telex。
2. 输入 `em`。
3. 按 `Space` 输入词间空格。
4. 输入 `trai`。
5. 按 `Enter` 提交 `em trai`。

最终上屏为 `em trai`。

## 示例

| 输入 | 候选 |
|---|---|
| `tooi` | `tôi` |
| `yeeu` | `yêu` |
| `tieengs` | `tiếng` |
| `vieetj` | `việt` |
| `em trai` | `em trai` |

若词表中没有对应候选，原始输入会作为兜底候选显示，可直接提交。
